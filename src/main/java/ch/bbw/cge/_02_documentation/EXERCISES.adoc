= Documentation Exercises

The exercises in this file use only the concepts explained in `README.adoc` and the Java files in this package.

== Check Your Understanding

. What is the difference between a line comment and a block comment?
. What is the purpose of Javadoc?
. What is the difference between a Javadoc tag and a Java annotation?
. When should a method have an `@return` tag?
. Give one example of a comment that would only repeat obvious code.

== Improve the Comment

Rewrite this code so that either the comment becomes useful or the variable name makes the comment unnecessary:

[source,java]
----
// Number of completed exercises
int n = 7;
----

== Write Javadoc

Write Javadoc for this method:

[source,java]
----
public String formatGreeting(String name) {
    return "Hello " + name;
}
----

Include an explanation, `@param`, and `@return`.

== Inspect the Example

Open `DocumentationExamples.java` and identify:
