= Documentation Exercises

== Check Your Understanding

. What is the difference between a Javadoc tag and a Java annotation?
. When should a method have an `@return` tag?
. Why can an `@throws` tag be useful even for an unchecked exception?
. Give one example of a bad comment that only repeats the code.

== Improve the Comment

Rewrite this comment so that either the comment becomes useful or the variable name makes it unnecessary:

[source,java]
----
// Increase x by one.
x++;
----

== Write Javadoc

Write Javadoc for this method:

[source,java]
----
public int divide(int dividend, int divisor) {
    if (divisor == 0) {
        throw new IllegalArgumentException("Divisor must not be zero.");
    }
    return dividend / divisor;
}
----

Include `@param`, `@return`, and `@throws`.
