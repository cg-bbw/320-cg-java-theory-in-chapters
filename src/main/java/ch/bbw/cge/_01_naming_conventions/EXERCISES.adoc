= Naming Convention Exercises

The exercises in this file use only the conventions explained in `README.adoc` and the code in `Main.java`.

== Check Your Understanding

. Which naming style is normally used for Java classes?
. Which naming style is normally used for methods?
. Which naming style is normally used for local variables and parameters?
. Why does this project use `_01_...` even though that is not the normal package convention?
. What is the difference between a compiler rule and a convention?

== Improve the Names

Rename the following identifiers so that their purpose becomes clearer:

[source,java]
----
int n = 4;
String s = "Zurich";
boolean x = true;
----

== Find the Convention Violations

[source,java]
----
class student_account {

    void Print_account_data() {
        String Customer_Name = "Robin";
    }
}
----

List every naming issue that is covered by this chapter and propose an improved name.

== Apply It

Create a copy of `Main.java` and rename the class, method, parameters, and local variables with different but still meaningful names.
Keep the naming styles from this chapter and make sure the new names still communicate their purpose.
