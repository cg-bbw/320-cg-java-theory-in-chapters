= Data Type Exercises – Lösungen

== Check Your Understanding

. Nenne alle acht primitiven Datentypen.
+
`byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`.

. Ist String ein primitiver Typ oder ein Referenztyp?
+
`String` ist ein Referenztyp, weil String eine Klasse ist.

. Was ist der Unterschied zwischen Deklaration und Initialisierung?
+
Bei der Deklaration werden Typ und Name einer Variable festgelegt.
Bei der Initialisierung erhält sie ihren ersten Wert.
+
[source,text]
----
int age;       // Deklaration
age = 18;      // Initialisierung
----
+
Beides kann auch zusammen erfolgen:
+
[source,text]
----
int age = 18;
----

. Was ist eine erneute Zuweisung (Reassignment)?
+
Eine bereits initialisierte Variable erhält einen neuen Wert.
+
[source,text]
----
int age = 18;
age = 19;      // Erneute Zuweisung
----

. Warum kann (int) 3.9 Informationen verlieren?
+
`int` kann keine Nachkommastellen speichern.
Beim Cast wird der Nachkommateil abgeschnitten.
Aus `3.9` wird `3`. Es wird nicht gerundet.

. Welche Wrapper-Klasse gehört zu boolean?
+
Die Wrapper-Klasse heisst `Boolean`.

== Identify the Types

=== Vier Variablen mit primitiven Typen

[cols="1,1,1", options="header"]
|===
|Variable |Typ |Anfangswert
|age |int |18
|temperature |double |21.5
|courseFinished |boolean |false
|grade |char |'A'
|===

=== Eine Variable mit Referenztyp

[source,text]
----
String courseName = "Java Fundamentals";
----

`courseName` hat den Referenztyp `String`.

=== Eine erweiternde Umwandlung (Widening)

[source,text]
----
double ageAsDouble = age;
----

Der int-Wert `18` wird automatisch in den double-Wert `18.0` umgewandelt.
Ein expliziter Cast ist hier nicht nötig.

=== Eine verengende Umwandlung (Narrowing)

[source,text]
----
int wholeTemperature = (int) temperature;
----

Der double-Wert `21.5` wird ausdrücklich zu `int` umgewandelt.
Der Nachkommateil geht verloren. Das Ergebnis ist `21`.

=== Eine Variable mit einer Wrapper-Klasse

[source,text]
----
Integer boxedAge = age;
----

`boxedAge` hat den Typ `Integer`, die Wrapper-Klasse für `int`.
Die automatische Umwandlung von `int` zu `Integer` heisst Autoboxing.

== Predict the Output

Gegebener Code:

[source,text]
----
double value = 8.7;
int whole = (int) value;
System.out.println(whole);
----

Ausgabe:

[source,text]
----
8
----

Der Cast zu `int` schneidet den Nachkommateil ab.
Deshalb wird `8` ausgegeben und nicht auf `9` gerundet.

== Choose a Type

. Alter einer Person: `int`
+
Das Alter in ganzen Jahren ist eine ganze Zahl.
+
[source,text]
----
int age = 18;
----

. Ob eine Tür offen ist: `boolean`
+
Es gibt zwei Zustände: offen (`true`) oder nicht offen (`false`).
+
[source,text]
----
boolean doorOpen = true;
----

. Produktpreis: `double` für dieses einfache Lernbeispiel
+
Ein Preis kann Nachkommastellen enthalten.
+
[source,text]
----
double productPrice = 19.90;
----
+
Hinweis: Für exakte Geldberechnungen verwendet man in echten Anwendungen
häufig `BigDecimal` oder speichert ganze Rappen als `int` beziehungsweise `long`,
weil `double` Rundungsabweichungen verursachen kann.

. Ein einzelnes Zeichen: `char`
+
`char` eignet sich beispielsweise für einen einzelnen Buchstaben.
Zeichen stehen in einfachen Anführungszeichen.
+
[source,text]
----
char initial = 'A';
----

. Vollständiger Name einer Person: `String`
+
Ein Name besteht aus mehreren Zeichen und kann Leerzeichen enthalten.
Text steht in doppelten Anführungszeichen.
+
[source,text]
----
String fullName = "Alex Morgan";
----
