= Data Types

== Learning Goals

After this chapter, you should be able to:

* distinguish primitive types from reference types;
* name Java's eight primitive types;
* declare, initialize, assign, and reassign variables;
* perform a simple widening or narrowing primitive conversion;
* explain the basic purpose of wrapper classes.

== Key Terms

Data type::
A classification that determines which kind of value a variable can hold and which operations are available for that value.

Primitive type::
One of Java's eight built-in non-reference types: `boolean`, `byte`, `short`, `int`, `long`, `char`, `float`, and `double`.

Reference type::
A type whose values are references to objects or arrays. `String` is a reference type because it is a class.

Wrapper class::
A class corresponding to a primitive type, for example `Integer` for `int` and `Double` for `double`.

Casting::
Explicitly requesting a compatible type conversion by writing the target type in parentheses.

== Reference Types

Classes, interfaces, arrays, records, and enum types are reference types.
A variable of a reference type can refer to an object or contain `null`.

[source,java]
----
String courseName = "Java Fundamentals";
----

`String` is a class, so `courseName` has a reference type.

Capitalization alone does not define whether a type is primitive or a reference type.
Uppercase class names are a naming convention.

== Declaration, Initialization, Assignment, and Reassignment

[source,java]
----
int age;       // declaration
age = 18;      // first assignment; the variable is now initialized
age = 19;      // reassignment
----

Declaration introduces the variable.
Initialization gives it its first usable value.
A later assignment replaces the previous value and is a reassignment.

== Widening and Narrowing

[source,java]
----
int count = 10;
double widerValue = count;

double price = 19.95;
int wholePrice = (int) price;
----

The first conversion can happen automatically because every `int` value can be represented as a `double` value at this introductory level.
The explicit cast in the second example is required because converting `double` to `int` can lose information.

== Wrapper Classes

Every primitive type has a corresponding wrapper class.

[cols="1,1"]
|===
|Primitive |Wrapper class

|`boolean` |`Boolean`
|`byte` |`Byte`
|`short` |`Short`
|`int` |`Integer`
|`long` |`Long`
|`char` |`Character`
|`float` |`Float`
|`double` |`Double`
|===

A wrapper is an object type that represents a primitive value.
For example:

[source,java]
----
Integer boxedAge = 18;
int age = boxedAge;
----

The automatic conversions between primitives and wrappers are called autoboxing and unboxing.

== Values and References

At Java source-code level, it is useful to distinguish primitive values from object references.
A reference should not be treated as if Java exposed a raw pointer that you manually manage.
Exact stack and heap placement is a runtime implementation detail and is not required to understand the type system in this chapter.

== Summary

Java distinguishes primitive types from reference types. Variables are declared and initialized before they are used, compatible values can be converted between types, and wrapper classes represent primitive values as objects.
