= Data Type Exercises

== Check Your Understanding

. Name all eight primitive types.
. Is `String` a primitive or a reference type?
. Why can `(int) 3.9` lose information?
. What is the wrapper class for `boolean`?
. Why is capitalization not a reliable definition of primitive versus reference type?

== Predict the Output

double value = 8.7;
int whole = (int) value;
System.out.println(whole);
----

What is printed and why?
