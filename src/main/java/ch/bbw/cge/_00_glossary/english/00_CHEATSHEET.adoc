= Java Programming Cheat Sheet
:toc:
:toclevels: 2

This cheat sheet is a quick orientation aid.
Use it when you remember the topic but not the exact term.
For full explanations, follow the links to the three glossaries.

== Program Structure

[cols="1,3,3",options="header"]
|===
|Term |Typical Java syntax |Quick meaning

|xref:01_JAVA_BASICS.adoc#jb-source-code[Source code]
|`*.java`
|Human-readable Java program text.

|xref:01_JAVA_BASICS.adoc#jb-package[Package]
|`package ch.school.example;`
|Groups related types in a namespace.

|xref:01_JAVA_BASICS.adoc#jb-import[Import]
|`import java.util.List;`
|Makes a type or static member available by a shorter name.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-class[Class]
|`class Car { ... }`
|Defines a reference type and the structure/behavior of its objects.

|xref:01_JAVA_BASICS.adoc#jb-main-method[Main method]
|`public static void main(String[] args)`
|Common entry point of a Java application.

|xref:01_JAVA_BASICS.adoc#jb-block[Block]
|`{ ... }`
|Groups statements and usually defines a local scope.

|xref:01_JAVA_BASICS.adoc#jb-statement[Statement]
|`total = price * amount;`
|A complete instruction or control-flow unit.

|xref:01_JAVA_BASICS.adoc#jb-expression[Expression]
|`price * amount`
|Code that is evaluated to produce a value or result.
|===

== Naming Conventions

[cols="2,2,3,3",options="header"]
|===
|Java element |Convention |Example |Note

|Class
|xref:01_JAVA_BASICS.adoc#jb-pascal-case[PascalCase]
|`BankAccount`
|Nouns are common class names.

|Interface
|xref:01_JAVA_BASICS.adoc#jb-pascal-case[PascalCase]
|`Printable`
|Often describes a capability or role.

|Record
|xref:01_JAVA_BASICS.adoc#jb-pascal-case[PascalCase]
|`CustomerAddress`
|Same type-naming style as classes.

|Enum type
|xref:01_JAVA_BASICS.adoc#jb-pascal-case[PascalCase]
|`OrderStatus`
|Enum constants themselves normally use UPPER_SNAKE_CASE.

|Method
|xref:01_JAVA_BASICS.adoc#jb-camel-case[camelCase]
|`calculateTotal()`
|Verb or verb phrase is common.

|Variable
|xref:01_JAVA_BASICS.adoc#jb-camel-case[camelCase]
|`numberOfStudents`
|Describe the value's meaning, not only its type.

|Parameter
|xref:01_JAVA_BASICS.adoc#jb-camel-case[camelCase]
|`maximumSpeed`
|Same convention as local variables.

|Constant
|xref:01_JAVA_BASICS.adoc#jb-upper-snake-case[UPPER_SNAKE_CASE]
|`MAX_SPEED`
|Commonly used for `static final` constants.

|Package
|xref:01_JAVA_BASICS.adoc#jb-lowercase[lowercase]
|`ch.school.examples`
|Normally lowercase, often based on a reversed domain/company structure.
|===

NOTE: xref:01_JAVA_BASICS.adoc#jb-snake-case[snake_case] is a common naming style in other technologies, but it is normally not used for ordinary Java variables or methods.

== Variables and Data Types

[cols="2,2,5",options="header"]
|===
|Term |Example |Quick meaning

|xref:01_JAVA_BASICS.adoc#jb-variable[Variable]
|`int age = 18;`
|A named storage location with a compile-time type.

|xref:01_JAVA_BASICS.adoc#jb-declaration[Declaration]
|`int age;`
|Introduces a program element to the compiler.

|xref:01_JAVA_BASICS.adoc#jb-initialization[Initialization]
|`int age = 18;`
|Gives a variable its first value.

|xref:01_JAVA_BASICS.adoc#jb-assignment[Assignment]
|`age = 18;`
|Stores a value in a variable.

|xref:01_JAVA_BASICS.adoc#jb-reassignment[Reassignment]
|`age = 19;`
|Assigns another value after an earlier one.

|xref:01_JAVA_BASICS.adoc#jb-primitive-type[Primitive type]
|`int`, `double`, `boolean`
|One of Java's eight built-in non-reference types.

|xref:01_JAVA_BASICS.adoc#jb-reference-type[Reference type]
|`String`, `Car`, `int[]`
|Type whose values refer to objects or arrays, or are `null`.

|xref:01_JAVA_BASICS.adoc#jb-wrapper-class[Wrapper class]
|`Integer`, `Double`
|Object representation corresponding to a primitive type.

|xref:01_JAVA_BASICS.adoc#jb-var[Var]
|`var name = "Ada";`
|Local-variable type inference; Java remains statically typed.

|xref:01_JAVA_BASICS.adoc#jb-final[Final]
|`final int max = 10;`
|Prevents reassignment or, in other contexts, overriding/extension.

|xref:01_JAVA_BASICS.adoc#jb-casting[Casting]
|`(int) 3.9`
|Explicitly requests a compatible type conversion.

|xref:01_JAVA_BASICS.adoc#jb-scope[Scope]
|`{ int x = 1; }`
|Source-code region in which a declared name is visible.
|===

== Operators and Program Flow

[cols="2,3,5",options="header"]
|===
|Term |Example |Quick meaning

|xref:01_JAVA_BASICS.adoc#jb-arithmetic-operator[Arithmetic operator]
|`+ - * / %`
|Performs numeric calculations.

|xref:01_JAVA_BASICS.adoc#jb-comparison-operator[Comparison operator]
|`== != < <= > >=`
|Compares values and produces `boolean`.

|xref:01_JAVA_BASICS.adoc#jb-logical-operator[Logical operator]
|`&& \|\| !`
|Combines or negates boolean values.

|xref:01_JAVA_BASICS.adoc#jb-if[If]
|`if (condition) { ... }`
|Executes a branch when a condition is true.

|xref:01_JAVA_BASICS.adoc#jb-else[Else]
|`else { ... }`
|Alternative branch when the associated `if` is false.

|xref:01_JAVA_BASICS.adoc#jb-switch[Switch]
|`switch (value) { case 1: ... break; default: ... }` +
`switch (value) { case ... -> ...; default -> ...; }`
|Two ways of a switch statement. Selects among several branches using `case`. `default` handles values that do not match another case.

|xref:01_JAVA_BASICS.adoc#jb-for[For]
|`for (int i = 0; i < 10; i++) { ... }` +
`for (String name : names) { ... }`
|Repeats code using either a traditional loop with a counter or an enhanced for loop over elements.

|xref:01_JAVA_BASICS.adoc#jb-while[While]
|`while (condition) { ... }`
|Pre-test loop.

|xref:01_JAVA_BASICS.adoc#jb-do[Do]
|`do { ... } while (condition);`
|Post-test loop that runs at least once.

|xref:01_JAVA_BASICS.adoc#jb-break[Break]
|`break;`
|Leaves the nearest loop or traditional switch.

|xref:01_JAVA_BASICS.adoc#jb-continue[Continue]
|`continue;`
|Skips to the next loop iteration.
|===

== Classes and Objects

[cols="2,3,5",options="header"]
|===
|Term |Example |Quick meaning

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-object[Object]
|`Car car = ...`

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-new[New]
|`new Car()`
|Starts creation of a new object or array.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-constructor[Constructor]
|`Car(String model) { ... }`
|Initializes a newly created object; not a method.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-this[This]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-instance-field[Instance field]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-static-field[Static field]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-instance-method[Instance method]

|xref:01_JAVA_BASICS.adoc#jb-access-modifier[Access Modifier]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-state[State]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-behavior[Behavior]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-identity[Identity]

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-equality[Equality]

== Inheritance, Interfaces, and Polymorphism

[cols="2,3,5",options="header"]
|===
|Term |Example |Quick meaning

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-extends[Extends]
|`class Dog extends Animal`
|Creates a class inheritance relationship.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-super[Super]
|`super.method()`
|Accesses direct-superclass behavior from an instance context.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-super-constructor[Super constructor invocation]
|`super(name);`
|Invokes a direct-superclass constructor.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-implements[Implements]
|`class Dog implements Trainable`
|Declares implementation of an interface contract.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-abstract-class[Abstract class]
|`abstract class Animal`
|Cannot be instantiated directly; may mix shared and abstract behavior.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-runtime-polymorphism[Runtime Polymorphism]
|Method overriding
|The actual object type determines at runtime which overridden method implementation is executed.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-method-overriding[Overriding]
|`@Override`
|Subclass provides a new implementation of an inherited method.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-compile-time-polymorphism[Compile-Time Polymorphism]
|Method overloading
|The compiler determines which method implementation is used based on the method signature and the arguments at the call site.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-method-overloading[Method Overloading]
|`print(int value)` +
`print(String value)`
|Multiple methods have the same name but different parameter lists. The compiler determines which method is called.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-upcasting[Upcasting]
|`Animal a = new Dog();`
|Views a subtype through a supertype reference.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-downcasting[Downcasting]
|`Dog d = (Dog) a;`
|Explicitly requests a more specific reference type.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-instanceof[Instanceof]
|`a instanceof Dog`
|Tests runtime type compatibility.

|xref:02_OBJECT_ORIENTED_PROGRAMMING.adoc#oop-dynamic-dispatch[Dynamic dispatch]
|`a.makeSound()`
|Runtime object determines overridden method implementation.
|===

== Design Principles and Patterns

[cols="2,3,5",options="header"]
|===
|Term |Short form |Quick meaning

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-kiss[KISS]
|Keep It Simple
|Avoid unnecessary complexity.

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-dry[DRY]
|Don't Repeat Yourself
|Avoid duplicated knowledge and rules.

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-yagni[YAGNI]
|You Aren't Gonna Need It
|Do not build speculative features too early.

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-srp[SRP]

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-ocp[OCP]

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-isp[ISP]

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-dip[DIP]

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-builder[Builder]

|Builds complex objects step by step.

|xref:03_ADVANCED_JAVA_CONCEPTS.adoc#adv-mvc[MVC]

|===

== Reserved and Specialized Words Not Required Here

* `const` and `goto`: reserved Java keywords, but the Java language does not use them.
* `strictfp`: reserved but obsolete; do not use it in new Java code.
* `native`, `synchronized`, `transient`, `volatile`: valid specialized keywords, but outside this learning project.
* Java module-system contextual keywords such as `module`, `requires`, `exports`, `opens`, `uses`, and `provides`: valid Java syntax, but outside this learning project.
