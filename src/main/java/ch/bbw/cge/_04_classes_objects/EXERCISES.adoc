= Classes and Objects Exercises – Lösungen

== Check Your Understanding

. Was ist der Unterschied zwischen einer Klasse und einem Objekt?
+
Eine Klasse ist ein Bauplan, der Felder und Methoden definiert.
Ein Objekt ist eine konkrete Instanz dieser Klasse.
`Car` ist die Klasse. Die beiden mit `new Car(...)` erstellten Autos sind Objekte.

. Was ist ein Instanzfeld?
+
Ein Instanzfeld ist eine Variable, die innerhalb der Klasse,
aber ausserhalb von Methoden und Konstruktoren deklariert wird.
Jedes Objekt besitzt eigene Werte für diese Felder.
Beispiele sind `model`, `year` und `speed`.

. Was ist der Unterschied zwischen einem Parameter und einem Argument?
+
Ein Parameter ist eine Variable im Methoden- oder Konstruktorkopf.
Ein Argument ist der tatsächlich übergebene Wert beim Aufruf.
Bei `accelerate(int targetSpeed)` ist `targetSpeed` der Parameter.
Beim Aufruf `firstCar.accelerate(50)` ist `50` das Argument.

. Warum hat ein Konstruktor keinen Rückgabetyp?
+
Ein Konstruktor ist ein spezielles Klassenmitglied zur Initialisierung
eines neuen Objekts. Er ist keine gewöhnliche Methode.
Java sieht für Konstruktoren keinen Rückgabetyp vor, auch nicht `void`.
Der Ausdruck `new Car(...)` liefert die Referenz auf das neue Objekt.

. Was bedeutet this.model = model;?
+
`this.model` ist das Instanzfeld des aktuellen Objekts.
`model` auf der rechten Seite ist der Konstruktorparameter.
Der übergebene Wert wird im Feld des Objekts gespeichert.

. Was ist der Unterschied zwischen Zustand und Verhalten?
+
Der Zustand besteht aus den aktuellen Werten der Instanzfelder,
beispielsweise Modell, Baujahr, Geschwindigkeit und Farbe.
Das Verhalten wird durch Methoden beschrieben, beispielsweise
`accelerate(...)`, das die Geschwindigkeit verändert.

== Mark the Code

=== Klassendeklaration

[source,text]
----
public class Car {
----

=== Drei ursprüngliche Instanzfelder

[source,text]
----
private String model;
private int year;
private int speed;
----

Mit der Erweiterung kommt ein viertes Instanzfeld hinzu:

[source,text]
----
private String color;
----

=== Ein Konstruktor

Der erweiterte Konstruktor lautet:

[source,text]
----
public Car(String model, int year, String color) {
    this.model = model;
    this.year = year;
    this.color = color;
}
----

=== Zwei Konstruktorparameter

* `String model`
* `int year`

Die Erweiterung ergänzt den Parameter `String color`.

=== Ein Methodenparameter

`int targetSpeed` in der Methode `accelerate`.

[source,text]
----
public void accelerate(int targetSpeed) {
    speed = targetSpeed;
}
----

=== Eine lokale Variable

`description` wird innerhalb von `getDescription()` deklariert
und ist nur innerhalb dieser Methode verfügbar.

[source,text]
----
String description = year + " " + model + " (" + color + ")";
----

=== Eine Methode mit Rückgabewert

`getSpeed()` gibt die aktuelle Geschwindigkeit als `int` zurück.

[source,text]
----
public int getSpeed() {
    return speed;
}
----

Auch `getDescription()` gibt einen Wert zurück, nämlich einen `String`.

== Extend the Example

Die Klasse `Car` wurde um das private Feld `color` erweitert.

Der Konstruktor erhält die Farbe als zusätzlichen Parameter
und speichert sie mit `this.color = color;`.

`getDescription()` enthält jetzt auch die Farbe.

Die Konstruktoraufrufe in `Main.java` wurden angepasst:

[source,text]
----
Car firstCar = new Car("Audi A3", 2023, "Black");
Car secondCar = new Car("VW Golf", 2022, "White");
----

== Explain the Call

[source,text]
----
firstCar.accelerate(50);
----

* Objektreferenz: `firstCar` enthält eine Referenz auf das erste Car-Objekt.
* Methodenname: `accelerate`.
* Argument: der Wert `50`.
* Passender Parameter: `int targetSpeed`.
* Wirkung: Das Feld `speed` des ersten Autos wird auf `50` gesetzt.
Die Geschwindigkeit des zweiten Autos bleibt unverändert bei `0`.

Die Methode setzt die Geschwindigkeit auf den übergebenen Wert.
Sie erhöht die bisherige Geschwindigkeit nicht um diesen Wert.
