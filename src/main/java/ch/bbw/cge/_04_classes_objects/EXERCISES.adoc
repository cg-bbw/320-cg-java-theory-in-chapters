== Check Your Understanding

. What is the difference between a class and an object?
A class is a blueprint that describes the fields and methods of objects. An object is a concrete instance created from a class.
. What is an instance field?
An instance field is a variable declared inside a class but outside methods and constructors. Every object has its own values for these fields.
. What is the difference between a parameter and an argument?
A parameter is a variable declared in a method or constructor. An argument is the actual value passed to that parameter when the method or constructor is called.
. Why does a constructor have no return type?
A constructor is a special class member that initializes a newly created object. It does not return a value.
. What does `this.model = model;` mean?
this.model refers to the instance field, while model refers to the constructor parameter. The statement assigns the parameter value to the instance field.
. What is the difference between object state and behavior?
State describes the current values stored in an object's instance fields.
Behavior describes what an object can do through its methods.
